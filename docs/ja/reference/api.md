## ユーザー向けインポート {#user-facing-imports}

Void のアプリ向け API は、次のパスからインポートします。

| インポートパス            | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `void`                    | `voidPlugin`、ハンドラー/型の再エクスポート、`defer`、`Deferred`、`DeferredState`、`InferProps`、`HeadDescriptor`                                                                                                                                                                                                                                                                                                                                                                                                             |
| `void/handler`            | `defineHandler`、`defineMiddleware`、`basicAuth`、`defineScheduled`、`defineQueue`、`defineRender`、`defineHead`、型                                                                                                                                                                                                                                                                                                                                                                                                          |
| `void/auth`               | `defineAuth`、`getUser`、`getSession`、`requireAuth`、`AuthUser`、`AuthSession`、`AuthState`                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `void/client`             | `fetch`、`fetchStream`、`FetchError`、`auth`、`createAuthClient`、`AuthUser`、`AuthSession`、`AuthState`                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `void/client/{framework}` | `void/client` と同じ内容に加え、`react`、`vue`、`svelte`、`solid` 向けのフレームワーク固有の Better Auth クライアント                                                                                                                                                                                                                                                                                                                                                                                                         |
| `void/ws`                 | `defineRoom`、`defineWebSocket`、`connect`、WebSocket のコンテキストと接続の型                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `void/durable`            | `defineDurableState`、`defineDurableObject`、型付きの state/RPC/context/migration の型                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `void/sse`                | `eventStream`、`formatSse`、`formatSseText`、`getLastEventId`、`SseStreamClosedError`、SSE のメッセージとストリームの型                                                                                                                                                                                                                                                                                                                                                                                                       |
| `void/sse/client`         | `connectEventStream`、ブラウザーの `EventSource` ラッパーの型                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `void/live`               | `defineLiveStream`、SSE トピックのファンアウトランタイムの型。サーバー専用。                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `void/live/client`        | `connectLiveStream`、1 つの SSE 接続と POST による subscribe/unsubscribe 制御のためのブラウザーヘルパー。                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `void/response`           | `convertReturnValue`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `void/validator`          | `runValidation`、`ValidatorSlots`、`HandlerInput`                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `void/drizzle-zod`        | Drizzle テーブルのスキーマから派生した Zod バリデーター用に [`drizzle-zod`](https://orm.drizzle.team/docs/zod) を再エクスポート                                                                                                                                                                                                                                                                                                                                                                                               |
| `void/drizzle-valibot`    | Drizzle テーブルのスキーマから派生した Valibot バリデーター用に [`drizzle-valibot`](https://orm.drizzle.team/docs/valibot) を再エクスポート                                                                                                                                                                                                                                                                                                                                                                                   |
| `void/drizzle-arktype`    | Drizzle テーブルのスキーマから派生した ArkType バリデーター用に [`drizzle-arktype`](https://orm.drizzle.team/docs/arktype) を再エクスポート                                                                                                                                                                                                                                                                                                                                                                                   |
| `void/schema-d1`          | D1 のテーブルとカラムのビルダー用に [`drizzle-orm/sqlite-core`](https://orm.drizzle.team/docs/column-types/sqlite) を再エクスポート                                                                                                                                                                                                                                                                                                                                                                                           |
| `void/schema-pg`          | PostgreSQL のテーブルとカラムのビルダー用に [`drizzle-orm/pg-core`](https://orm.drizzle.team/docs/column-types/pg) を再エクスポート                                                                                                                                                                                                                                                                                                                                                                                           |
| `void/schema-mysql`       | MySQL のテーブルとカラムのビルダー用に `drizzle-orm/mysql-core` を再エクスポート                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `void/database-provider`  | `void db connect --provider` 用の `defineDatabaseProvider` とアダプターの型                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `void/db`                 | `db`(有効なダイアレクト向けの Drizzle D1、PostgreSQL、または MySQL インスタンス)、`createDb`、クエリ演算子(`eq`、`and`、`or`、`desc`、`like`、`inArray` など)                                                                                                                                                                                                                                                                                                                                                                 |
| `void/seed`               | プログラムによる `void db seed` モジュール用の `defineSeed`、`SeedContext`、`SeedFn`                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `void/kv`                 | `kv`、`createKV`、型付きの KV クライアント/マップの型                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `void/storage`            | 推論された R2 バインディングまたは特定の `R2Bucket` 用の `storage`、`createStorage`                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `void/ai`                 | `ai`、`VoidAi`、モデルの入力とレスポンスの型                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `void/limits`             | `UsageLimit`、`UsageLimitData`、`readUsageLimit`。AI とサンドボックスの制限は `UsageLimit` で reject されます。Void のルートと Pages アクションで捕捉されなかった制限は、構造化された HTTP 429 レスポンスを返します。                                                                                                                                                                                                                                                                                                         |
| `void/isr`                | オンデマンドの ISR キャッシュ無効化のための `revalidate(options)`                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `void/log`                | 構造化ロギングヘルパーの `logger`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `void/routes`             | `RouteMap` と `WebSocketRouteMap` のスタブ(型のみ)                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `void/queues`             | 型付きキューにメッセージを送信するための `queues` プロキシ                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `void/email`              | `sendEmail`、`createEmail`、`defineEmail`、`parseEmail`、`replyEmail`、`MimeError`、`ParseEmailError`、およびアドレス、添付ファイル、結果、ハンドラーの型。[メール](../guide/email.md)を参照してください。                                                                                                                                                                                                                                                                                                                    |
| `void/email/testing`      | 送信をキャプチャし、テストメッセージを `email/` ハンドラーに配信するための `createEmailTestHarness` と `createInboundTestHarness`。                                                                                                                                                                                                                                                                                                                                                                                           |
| `void/sandbox`            | `getSandbox`、`sandbox`、`SandboxLimitError`、`SandboxUnavailableError`、および SDK 1.0 のファイル、バックアップ、マウントのヘルパー。`getSandbox(id)` はクライアントを解決します。コマンド、ファイル、ポートリクエスト、プロセスの完了はプロミスを返します。制限は `UsageLimit` を拡張した `SandboxLimitError` で reject されます。コンテナの状態は、非アクティブ状態(デフォルトは 10 分)、クラッシュ、または再起動まで維持されます。API とデプロイ要件については[サンドボックス](../guide/sandboxes.md)を参照してください。 |
| `void/env`                | `defineEnv`、`env`、スキーマヘルパー(`string`、`number`、`boolean`、`url`、`email`、`oneOf`、`json`)、およびグローバルな Cloudflare の env の型                                                                                                                                                                                                                                                                                                                                                                               |
| `void/nitro`              | Nuxt と Analog 向けの Nitro モジュール。Nitro の `modules` に `'void/nitro'` を追加すると、サーバールートがアプリの `void/db` と `@schema` を利用できます                                                                                                                                                                                                                                                                                                                                                                     |
| `void/sveltekit`          | SvelteKit インテグレーションのヘルパー: `withVoidTSConfig()` と `mergeVoidSvelteKitTsconfig()`                                                                                                                                                                                                                                                                                                                                                                                                                                |
